# 小红书爆款笔记爬取器 - 设计文档

## 1. 项目概述

### 1.1 项目目标
开发一个 Python 脚本，用于爬取小红书特定关键词搜索结果的爆款笔记数据，并导出为 CSV/Excel 格式。

### 1.2 功能需求
- 用户运行时输入搜索关键词
- 自动筛选发布时间为"一周内"的笔记
- 爬取前 30 篇笔记的详细信息
- 支持重试机制（失败后重试 3 次）
- 无法访问的笔记标记为"无法访问"并继续
- 输出 CSV 文件到 `output/` 目录

### 1.3 爬取字段
| 字段 | 说明 |
|------|------|
| 序号 | 1-30 |
| 作者 | 笔记作者昵称 |
| 标题 | 笔记标题 |
| 点赞数 | 点赞数量 |
| 收藏数 | 收藏数量 |
| 评论数 | 评论数量 |
| 封面 URL | 封面图片或视频链接 |
| 笔记链接 | 笔记的完整 URL |
| 正文内容 | 笔记正文文本 |
| 发布时间 | 笔记发布日期 |
| 状态 | 成功/无法访问 |

## 3. 模块设计

### 3.1 输入模块 (input.py)

**功能：**
- 获取用户输入的搜索关键词
- 获取用户手动复制的 Cookie
- 验证输入的有效性

**接口：**
```python
def get_keyword() -> str
def get_cookie() -> str
def parse_cookie(cookie_str: str) -> dict
```

### 3.2 爬取模块 (crawler.py)

**功能：**
- 构造搜索请求 URL
- 发送 HTTP 请求获取搜索结果
- 解析笔记列表数据
- 获取每篇笔记的详细信息
- 实现重试机制

**核心流程：**
```
1. 构造搜索 URL (带 keyword 和筛选参数)
2. 发送请求获取搜索结果页
3. 解析页面中的笔记 ID 列表
4. 遍历前 30 篇笔记:
   a. 构造笔记详情 API 请求
   b. 获取笔记详细信息
   c. 失败时重试 (最多 3 次)
   d. 提取所需字段
5. 返回笔记数据列表
```

**接口：**
```python
def search_notes(keyword: str, cookie: str, limit: int = 30) -> list
def get_note_detail(note_id: str, cookie: str, retry: int = 3) -> dict
def parse_search_results(html: str) -> list
```

### 3.3 存储模块 (storage.py)

**功能：**
- 创建 output 目录
- 将笔记数据转换为 DataFrame
- 导出为 CSV 文件
- 文件命名：`爆款笔记_关键词_日期.csv`

**接口：**
```python
def save_to_csv(notes: list, keyword: str, output_dir: str = "output") -> str
def create_output_dir(output_dir: str) -> str
```

### 3.4 工具模块 (utils.py)

**功能：**
- Cookie 字符串解析为字典
- 构造请求头
- 数据清洗（去除 HTML 标签、处理数字格式等）
- 日志记录

**接口：**
```python
def parse_cookie(cookie_str: str) -> dict
def build_headers(cookie: dict) -> dict
def clean_text(text: str) -> str
def format_number(num_str: str) -> int
def setup_logger() -> logging.Logger
```

## 5. API 分析策略

### 5.1 首选方案：直接 API 调用

**目标：** 分析小红书网页版的 API 接口，直接发送 HTTP 请求获取数据。

**步骤：**
1. 使用浏览器开发者工具 (F12) 抓包
2. 搜索时观察 Network 面板的 XHR/Fetch 请求
3. 找到返回笔记列表的 API 端点
4. 分析请求参数（keyword、筛选条件、分页等）
5. 分析响应数据格式（JSON 结构）
6. 在脚本中复现请求

**关键参数（待确认）：**
- `keyword`: 搜索关键词
- `page`: 页码
- `page_size`: 每页数量
- `filter_type`: 筛选类型（一周内）
- `sort_type`: 排序类型（综合）

### 5.2 备用方案：Playwright 模拟

如果直接 API 调用不可行（如参数加密、签名验证等），则使用 Playwright 模拟真实用户操作。

**流程：**
1. 启动浏览器（带用户 Cookie）
2. 打开搜索页面
3. 等待页面加载完成
4. 点击筛选按钮选择"一周内"
5. 等待数据加载
6. 滚动页面加载更多笔记
7. 解析页面 DOM 获取笔记数据
8. 遍历每篇笔记获取详情

## 6. 错误处理策略

### 6.1 重试机制
- 每篇笔记请求失败后重试 3 次
- 重试间隔：1 秒、2 秒、4 秒（指数退避）
- 3 次失败后标记为"无法访问"

### 6.2 异常类型处理
| 异常类型 | 处理方式 |
|----------|----------|
| 网络超时 | 重试 |
| Cookie 失效 | 提示用户重新获取 |
| 笔记已删除/私密 | 标记"无法访问"，继续 |
| 请求被限流 | 等待 30 秒后重试 |
| 解析失败 | 记录日志，标记"无法访问" |

### 6.3 日志记录
- 使用 logging 模块记录运行日志
- 日志文件：`logs/crawler_日期.log`
- 日志级别：INFO（正常）、WARNING（警告）、ERROR（错误）

## 9. 使用说明

### 9.1 环境准备
```bash
# 激活虚拟环境
conda activate base

# 安装依赖
pip install -r requirements.txt

# 安装 playwright 浏览器 (如需备用方案)
playwright install chromium
```

### 9.2 获取 Cookie
1. 打开浏览器，访问 https://www.xiaohongshu.com/explore
2. 登录小红书账号
3. 按 F12 打开开发者工具
4. 切换到 Network 标签，刷新页面
5. 点击任意请求，找到 Request Headers 中的 Cookie
6. 复制完整的 Cookie 字符串

### 9.3 运行脚本
```bash
python main.py
```

按提示输入：
1. 搜索关键词（如：claude）
2. Cookie 字符串

### 9.4 查看结果
爬取完成后，CSV 文件保存在 `output/` 目录下。

## 10. 风险与限制

### 10.1 技术风险
- 小红书 API 可能变更，需要定期维护
- 反爬机制可能升级（验证码、IP 限制等）
- Cookie 有有效期，过期需要重新获取

### 10.2 法律风险
- 请确保爬取行为符合小红书用户协议
- 数据仅用于个人学习研究，不要用于商业用途
- 注意个人隐私和数据保护

### 10.3 性能限制
- 爬取 30 篇笔记预计耗时 1-3 分钟
- 大量并发请求可能触发限流
- 建议单次运行间隔不少于 5 分钟
