# 小红书爆款笔记爬虫

基于 Playwright 的小红书笔记爬取工具，模拟真实浏览器操作，支持手动筛选后爬取。

## 功能特点

- ✅ 模拟真实浏览器操作，规避反爬
- ✅ 支持手动筛选（时间范围、排序方式等）
- ✅ 精确提取笔记数据（标题、作者、点赞、收藏、评论等）
- ✅ 自动处理"万"单位的数字（如 1.2 万 → 12000）
- ✅ 错误控制机制（连续失败自动跳过）
- ✅ 爬取速度快（约 4-5 秒/篇）

## 环境要求

- Python 3.8+
- Windows 10/11

## 安装步骤

### 1. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

### 2. 安装 Playwright 浏览器

```bash
playwright install chromium
```

## 使用方法

### 步骤 1：获取 Cookie

1. 打开浏览器，访问 [小红书](https://www.xiaohongshu.com)
2. 登录你的账号
3. 按 `F12` 打开开发者工具
4. 进入 **Network（网络）** 标签
5. 刷新页面，点击任意请求
6. 复制 **Request Headers** 中的完整 `Cookie`

### 步骤 2：运行爬虫

```bash
python main.py
```

### 步骤 3：输入 Cookie

将复制的 Cookie 粘贴到命令行中，按回车

### 步骤 4：输入搜索关键词

例如：`黑丝 `、` 穿搭 `、` 美妆` 等

### 步骤 5：手动筛选（重要！）

浏览器会自动打开搜索结果页面，此时：

1. 点击顶部的 **"筛选"** 按钮
2. 选择 **"发布时间"** → **"一周内"**（或其他）
3. 可选择 **"排序依据"** → **"最多点赞"**（可选）
4. 筛选完成后，回到命令行 **按回车键**

### 步骤 6：等待爬取完成

爬虫会自动：
- 提取搜索结果页的所有笔记
- 逐个点开笔记详情页
- 提取标题、作者、点赞数、收藏数、评论数、封面图、正文内容
- 保存数据到 CSV 文件

## 输出说明

爬取完成后，数据保存在 `output/` 目录下，文件名格式：

```
爆款笔记_关键词_YYYYMMDD_HHMMSS.csv
```

### CSV 字段说明

| 字段 | 说明 |
|------|------|
| 序号 | 笔记序号 |
| 作者 | 笔记作者昵称 |
| 标题 | 笔记标题 |
| 点赞数 | 点赞数量（自动处理"万"单位） |
| 收藏数 | 收藏数量 |
| 评论数 | 评论数量 |
| 封面 URL | 笔记封面图片链接 |
| 笔记链接 | 笔记详情页链接 |
| 正文内容 | 笔记正文描述 |
| 状态 | 爬取状态（成功/无法访问） |

## 配置说明

### 修改爬取数量

编辑 `config.py`，修改 `LIMIT` 参数：

```python
CRAWLER_CONFIG = {
    "LIMIT": 30,  # 默认爬取 30 篇
}
```

### 修改输出目录

编辑 `config.py`，修改 `OUTPUT_DIR`：

```python
OUTPUT_CONFIG = {
    "OUTPUT_DIR": "output",  # 输出目录
}
```

## 常见问题

### Q: 爬取失败怎么办？

A: Cookie 可能已过期，重新获取最新 Cookie 后再试

### Q: 爬取速度太慢？

A: 检查网络连接，或减少爬取数量

### Q: 点赞数显示为 0？

A: 可能是页面缩放问题，确保浏览器窗口大小正常

### Q: 连续失败次数过多？

A: 可能是账号被风控，更换 Cookie 或降低爬取频率

## 技术细节

### 为什么选择模拟浏览器？

- 小红书 API 有复杂的签名验证（X-s 系列 header）
- Cookie 风控严格，API 验证更严
- 模拟真实用户操作，稳定性更好

### 爬取流程

```
输入 Cookie → 打开搜索页 → 手动筛选 → 按回车 → 
提取笔记列表 → 逐个点击 → 提取详情 → 返回列表 → 
滚动加载 → 继续爬取 → 达到数量 → 保存 CSV
```

### 优化机制

- 页面缩放 100% 确保数据完整显示
- 智能等待（URL 变化 + 选择器出现）
- 连续失败控制（10 次失败自动停止）
- 单 ID 失败限制（3 次失败自动跳过）
- 最大滚动次数限制（20 次）
