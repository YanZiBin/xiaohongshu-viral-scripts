# 小红书爆款笔记爬取器

爬取小红书特定关键词搜索结果的前 30 篇笔记数据，导出为 CSV/Excel 格式。

## 功能特点

- ✅ 支持自定义搜索关键词
- ✅ 自动筛选一周内发布的笔记
- ✅ 爬取笔记详细信息（作者、标题、点赞、收藏、评论、封面、正文）
- ✅ 支持重试机制
- ✅ 导出 CSV/Excel 格式
- ✅ 完整的日志记录

## 快速开始

### 1. 环境准备

```bash
conda activate base
pip install -r requirements.txt
```

### 2. 获取 Cookie

1. 打开浏览器，访问 https://www.xiaohongshu.com/explore
2. 登录小红书账号
3. 按 F12 打开开发者工具
4. 切换到 Network 标签，刷新页面
5. 点击任意请求，复制 Request Headers 中的完整 Cookie

### 3. 运行脚本

```bash
python main.py
```

按提示输入：
- 搜索关键词（如：claude）
- Cookie 字符串

### 4. 查看结果

爬取完成后，CSV 文件保存在 `output/` 目录下。

## 输出字段

| 字段 | 说明 |
|------|------|
| 序号 | 1-30 |
| 作者 | 笔记作者昵称 |
| 标题 | 笔记标题 |
| 点赞数 | 点赞数量 |
| 收藏数 | 收藏数量 |
| 评论数 | 评论数量 |
| 封面 URL | 封面图片或视频链接 |
| 笔记链接 | 笔记的完整 URL |
| 正文内容 | 笔记正文文本 |
| 发布时间 | 笔记发布日期 |
| 状态 | 成功/无法访问 |

## 注意事项

1. 请确保爬取行为符合小红书用户协议
2. 数据仅用于个人学习研究，不要用于商业用途
3. Cookie 有有效期，过期需要重新获取
4. 建议单次运行间隔不少于 5 分钟，避免触发限流
